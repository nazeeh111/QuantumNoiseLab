METHOD & LIMITS
Model assumptions
Frequencies are in MHz and time is in microseconds. The Hamiltonian uses angular frequencies internally. Ground is |0⟩, excited is |1⟩. T₂ follows 1/T₂ = 1/(2T₁) + 1/Tφ.
Echo uses an ideal instantaneous π pulse at half the delay. It refocuses static detuning, not irreversible Markovian noise. Preparation and readout are ideal; optional shot noise is synthetic.
